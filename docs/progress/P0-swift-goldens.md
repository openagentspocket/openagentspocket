notes:
- First pass: the worker's worktree was in the Swift repo and the session's isolation guard refused git aimed at agentico-app, so the payload was staged outside the repo. The review fix created the agentico-app worktree and landed it; the README license hunk was rebased on the License section as rewritten by aac5324/0ba3ab9 (it names `modules/ssh/ios` and `modules/ssh/android`).
- The goldens are a reflection of the Swift values, not their `Codable` form: they include stored properties the cache encoding drops (`ChatToolActivity.preview`, `cardAnswer`, `outputRead`, `isNotUpdating`). A port maps its own types into this image in the test and deep-compares parsed JSON.
- OpenCode line offsets are not byte offsets: rows sit at their `seq`, session and inbox lines at `event_seq + 1` (`lineOffsets` in each golden records what was fed).
- Dialog fingerprints are SHA-256 hex of `DialogRowScanner.comparable` fields joined by U+001F/U+001E; compare them last.
- Refusal messages are English because of `-testLanguage en`; a run in another language changes only `{"error": {"unsupported": "..."}}` texts.
