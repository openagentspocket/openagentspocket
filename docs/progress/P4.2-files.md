notes:
  - Core imports no SSH types: `FileSshSession`/`FileSftp` are the structural subset of `SshSession`/`Sftp` the browser uses (the real client satisfies them), and the device sandbox is the `LocalFiles` port (`ExpoLocalFiles` in the app, `FakeLocalFiles` for tests and Demo). Tests run the real `SftpFileBrowserHost` over `FakeSsh` from modules/ssh via a relative import in `fixture.test-util.ts`.
  - `FileBrowserStore` is a plain class with `getState`/`subscribe` (immutable snapshots, read with `useSyncExternalStore`); transfers live in `FileTransfers` (split for the 400-line budget) behind the same store API. Late answers are dropped with sequence numbers instead of task cancellation; downloads and uploads take a `CancelSignal`.
  - Each SFTP operation opens its own channel and closes it after (as Swift), so a browser left open holds no session slot.
  - Uploads stage as `.<name>.agentico-<8 hex>.part` (0600), are size-checked, chmod'ed, then renamed; a part that cannot be removed is remembered and the next listing deletes it, as is any part untouched for an hour. The SSH module's own replace-write uses a `.tmp` sibling; the browser does not use it because it must also refuse folders and links.
  - Git ignore check differs from Swift's framed script: one `git check-ignore -z --stdin` exec with the names on stdin (`ExecOptions.input`), `./`-prefixed so no pathspec magic parses them; exit 0 and 1 are answers, anything else dims nothing.
  - Photo upload: the picker re-encodes without EXIF at 0.8 quality; the Swift 4096 px / 16 MiB re-encode is not reproduced (the 64 MiB cap applies).
  - `HOME_COMMAND`, `FakeLocalFiles` are exported from core for the app's Demo source and tests.
