- Dependencies added: packages/ui: `expo-symbols ~58.0.4` (already native in the app), `expo-clipboard ~58.0.4` (native, new), `@shopify/flash-list 2.3.2` (JS only), `marked ^18.1.2` (JS only, MIT). apps/mobile: `expo-clipboard` via `npx expo install` (autolinking).

- Overlay hosts form a stack: the most recently mounted OverlayHost presents. Sheet mounts its own while open (iOS cannot present a root-level modal over another modal); the gallery mounts its own to draw in its theme.
- Button drops a promise returned by `onPress`, so `onPress={() => confirm(...)}` does not deadlock RNTL's awaited `fireEvent.press` (it awaits the handler's result).
- RNTL 14: `toBeChecked` only accepts checkbox/radio/switch; menu items and modifier keys also set `selected`, which tests query.
- `Markdown` takes `text`, not children (biome's noReactNativeRawText flags string children).
- SectionHeader's count badge now uses the control style (Swift's CapsuleBadge .control); Home shows it that way.
- Strings a primitive owns are props with English defaults (Cancel, OK, Close, Copied, Send, Stop, Loading, DiffView's line heads), ready for the i18n task to pass translations.
- Review fixes (judge round 1): DiffView row labels; StatusDot/ProgramMark glyphs at accessibility sizes (4 icons `statusBlocked/Done/Working/Idle` in Icon.tsx; Android uses error, check_circle, radio_button_checked, radio_button_unchecked because expo-symbols draws the static outlined Material font, where circle would be a ring for both working and idle); transparent rows plus `SurfaceFillProvider`/`useSurfaceFill()` (Card by level, Sheet as surfaceOverlay, canvas outside both) for SwipeRow's front and ProgramMark's ring default; `scrim` token (Índigo and Noche #000000, Papel its ink #1F1B16) behind `theme.backdrop` at 45%; Shift in `KeyModifier`; section-namespaced VirtualSectionList keys.
- Accessibility-size threshold: 1.4, not 1.35. React Native reports iOS xxxLarge (a standard size, not `isAccessibilitySize`) as 1.353 and AX1 as 1.786; 1.35 would switch one size early. Android steps are 1.3 and 1.5.
- jest: React Native's jest preset reports font scale 2 (an accessibility size), so `packages/ui/jest.setup.js` resets it to 1 before every test in both the ui and app jest configs; `setFontScale(n)` from src/test-utils sets another before rendering.
- Icon on Android at large font scales: expo-symbols draws a Text glyph sized `size` in a `size` box, and Text scales with the system font, so glyphs can outgrow their box there. Not fixed here; worth a check in the integrator's Android pass.
