notes:
- Row model is `ConsoleRow` (wire `AgentInfo` + Host and snapshot facts), immutable; `ConsoleAgent` in agents.ts stays the flat demo type until Home migrates. Row identity is `agentKey(hostId, paneId)`.
- Deviation from Swift: a Host with no entry in `sortByHost` is `priority` and gets the stateChangeSeq/snapshotOrder tiebreaks (Swift skipped them for the empty map; the store always passed every Host, so app behavior is the same; the saved-chat call with `[:]` is the only difference).
- Projection lifecycle passthroughs (`resume`, `suspend`, `cancelConnecting`) are not duplicated: call them on `projection.session`. `retry`/`revalidate`/`end` stay on the projection because they also reset its state.
- Times in stamps and the inbox are epoch milliseconds; durations are milliseconds.
- `SyncError` carries a kind, not text, so the UI picks the words through t().
- Lesson: `updateSubscriptions` with a changed set ends the stream and yields a fresh `connected`, i.e. one more snapshot; tests that count snapshots use protocol 18 or a stable set.
