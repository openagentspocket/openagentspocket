notes:
- Dev dependencies added to packages/i18n: vitest ^5.0.5 (as core) and intl-messageformat ^12.1.4 (BSD-3-Clause, tests only, never bundled). No runtime dependency.
- The runtime is a ~250-line ICU subset (args, number, plural with `#`, apostrophe quoting) with CLDR en/es plural rules, pinned against Node's Intl.PluralRules and intl-messageformat; this avoids an Intl.PluralRules polyfill on Hermes.
- Number args format with the full locale tag (es-AR → 12.345), like Foundation's localized `%lld`; plural choice uses the catalog language.
- Keys without arguments are literal (Swift never formats them), so `%ProgramData%` stays as written; keys with arguments are format strings.
- Converter default Swift path is a sibling `Agentico` checkout of the repo; in a worktree pass `--swift <dir>` or set AGENTICO_SWIFT_DIR. The sync test skips when the checkout is missing; the integrator should run it once with the env var.
- `pnpm -F @openagentspocket/i18n convert -- --swift <dir>` after any Swift catalog change; never edit the JSON.
