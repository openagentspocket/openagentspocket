# 0019. Push: raw device tokens, end-to-end encrypted payloads

Status: accepted (2026-11-01)

## Decision

expo-notifications raw tokens. iOS: the NSE decrypts (relay unchanged). Android: FCM data-only messages decrypted by a small Kotlin FirebaseMessagingService. The relay gains a `platform` field and an FCM HTTP v1 path.

## Why

The relay never sees plaintext on either platform.
