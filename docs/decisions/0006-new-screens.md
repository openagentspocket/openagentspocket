# 0006. New screens: Focus mode, overview board, two-line summaries

Status: accepted (2026-11-01)

## Decision

Focus mode (one card per Agent that needs you, numbered options, one tap answers, next card); an overview board (every Agent on every Host, only those that need you stand out, user-set priorities); a two-line summary per Agent (what it did, what it needs). Inspired by agentbox's ideas, with no code copied.

## Why

Triage speed is the product: answer many Agents in a few taps.
