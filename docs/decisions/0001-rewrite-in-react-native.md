# 0001. Rebuild Agentico in React Native + Expo

Status: accepted (2026-11-01)

## Decision

Rebuild the native iOS app in React Native with Expo for iOS and Android, with feature parity before any store release. The native Swift app is the reference and the spec (docs/spec/parity.md) until parity.

## Why

One codebase for two platforms; the JS ecosystem also lets agents and contributors work without Xcode for most changes.
