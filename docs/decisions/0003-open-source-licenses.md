# 0003. Open source: MIT, with Apache-2.0 for the Heeler-derived packages

Status: accepted (2026-11-01)

## Decision

New code is MIT. `packages/plugin` and `packages/relay` derive from Heeler (Apache-2.0) and keep that license with a NOTICE crediting it. The repo carries no personal infrastructure: docs say "your Host".

## Why

Respects the upstream license; keeps the repo usable by anyone. GPL code (for example agentbox, GPL-3.0) is studied for ideas but never copied.
