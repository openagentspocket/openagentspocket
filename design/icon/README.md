# OpenAgentsPocket icon, final (C · Cards), dark metal finish

Generated by `gen_final.py` from the mark's one definition, `packages/ui/tokens/mark.json` (geometry and
palette, shared with the in-app mark and the launch animation). Run from this folder:

```sh
python3 -I gen_final.py                 # approved finish (metal), fan angle from the token (26)
python3 -I gen_final.py 26 --finish flat  # the previous white and grey finish, same names
```

Chrome headless renders the SVGs. The script writes the files below and copies the app's assets to
`apps/mobile/assets/images/` (`icon.png`, `android-icon-{foreground,background,monochrome}.png`, `favicon.png`).
Never edit those PNGs by hand.

## Colors (metal, approved 2026-11-13)
- Background solid `#000000`.
- Each piece is a vertical gradient (top to bottom): left card `#3B3F46` to `#17191C`, right card `#4D525A` to
  `#1E2024`, front card `#747A84` to `#2B2E33`, pocket `#454950` to `#141518`.
- Rim of light: a 12 px stroke on every piece, white fading from opacity 1 (top) to 0.08 (55%) to 0 (bottom).
- Gaps between cards, and between cards and pocket, are real cut-outs (masks), not painted strokes, so the mark
  works on any background.
- The launch animation adds the spectrum `#6D28FF` / `#D21FE0` / `#FF2D55` / `#FF7A18` (violet to orange); the icon
  does not use it.

Flat finish (kept reproducible with `--finish flat`): pocket `#6E6E6E`; front card `#FFFFFF`; side cards `#FFFFFF` at
55% and 80% opacity.

## What changed
- 2026-11-13: dark metal pieces with a rim of light replace the flat white and grey. The geometry moved to
  `packages/ui/tokens/mark.json`. The splash images are gone: the native splash is plain black and the app draws
  the mark itself (`LaunchOverlay` in `packages/ui`).

## Small-size refinement
Fan of 3 narrow cards (+/-26 degrees, 270 px wide) rising well above a shorter pocket, with 26 px gaps; the front
card plus the two side edges still read as three at 29 px and as a "face" (centre card + ears) at 60 px.

## Files
- `ios-icon-1024.png`: iOS icon, 1024x1024, opaque, unmasked (iOS applies the corner mask). `hasAlpha: no` (the
  script fails if it is not).
- `android-foreground-1024.png`: adaptive foreground, transparent, mark scaled to fit inside the 66% safe circle
  (diameter 676 px, 3% margin).
- `android-background-1024.png`: adaptive background, opaque `#000000`.
- `android-monochrome-1024.png`: Android 13 themed icon, single black silhouette on transparent, same safe zone,
  gaps kept (unchanged by the finish).
- `favicon-48.png`: 48 px, rounded corners, transparent corners.
- Previews and sources: `contact.png` (180/60/29 px on light and dark), `preview-{180,60,29}.png` (masked),
  `icon-metal.svg`, `icon-flat.svg`, `android-foreground.svg`, `gen_final.py`.

## Expo wiring (apps/mobile/app.json)
```json
{
  "icon": "./assets/images/icon.png",
  "android": { "adaptiveIcon": {
    "backgroundColor": "#000000",
    "foregroundImage": "./assets/images/android-icon-foreground.png",
    "backgroundImage": "./assets/images/android-icon-background.png",
    "monochromeImage": "./assets/images/android-icon-monochrome.png" } },
  "web": { "favicon": "./assets/images/favicon.png" },
  "plugins": [["expo-splash-screen", { "backgroundColor": "#000000" }]]
}
```
Caveat: the foreground is a dark mark on transparent; check it over a black background.
