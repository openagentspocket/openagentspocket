Lobe Icons (agent program logos)
https://github.com/lobehub/lobe-icons, npm package @lobehub/icons-static-svg@1.101.0
(icons/<name>.svg, the single-color variants)

Agentico draws these marks to show which program an Agent runs. Each SVG
path is copied unchanged; only the root element's size was fixed to 24 and
its inline style removed. The logos are trademarks of their respective
owners. Showing them does not imply any affiliation with, or endorsement by,
those owners.
